# Critical Demo Flow

The MVP is successful when this works reliably:

1. Customer enters application.
2. Personalized products are shown.
3. Customer views an event menu.
4. Customer asks AI for desserts for an event/serving count.
5. AI-assisted recommendation uses real catalog products.
6. Customer adds recommended products to cart.
7. Customer checks out.
8. Order persists in MongoDB.
9. Inventory decreases.
10. Franchise view sees the order/inventory state.
11. Analytics reflects the order.
12. Customer chooses a subscription.
13. Subscription persists and displays as active.

Do not sacrifice this flow for visual polish or production infrastructure.
